# v2.1.0 코드 다이어트 (ponytail-audit)

동작은 그대로 두고, 없어도 되는 추상화와 복붙만 줄인다. 점검 중 재현된 두 버그는 같은 릴리스에서 고친다.

## 이번 버전에서 한다

| 태그 | 내용 | 위치 |
|------|------|------|
| shrink | HTTP 실패 매핑 공유 | ChzzkClient, SoopClient |
| shrink | 즐겨찾기 쓰기 핸들러 공통 가드 | FavoriteEndpoints |
| yagni | `IProgressiveLiveSource` 제거. `ILiveSource` 기본 구현으로 부분 게시 | ILiveSource, Worker, 클라, 테스트 |
| yagni | SOOP `Parallel.ForEachAsync` DOP=1 → `for` | SoopClient |
| delete | 런타임이 안 부르는 `Validate` / 비밀 숨김용 `ToString` | ChzzkOptions, SoopOptions |
| yagni | `FavoriteStoreInitializer` hosted service → `Program`에서 try/catch 초기화 | Program, Favorites |
| shrink | 홈 태그 랭킹 한 번만 정렬 | Index.cshtml.cs |
| yagni | `StaleAfter` 한곳 | CollectionSnapshot |
| delete | CollectionRegistry XML 주석. `ConcurrentBag` → `List` | CollectionRegistry |
| shrink | 워커 등록 복붙 | Program |
| yagni | 안 쓰는 SOOP DTO 필드 | SoopDtos |
| yagni | `FavoriteStatus` enum → 문자열 | FavoriteCatalog |
| shrink | `LiveStream`을 record primary ctor로 | LiveStream |

## 이번 버전에서 안 한다

- `favorites.js` DOM을 `<template>`로 갈아엎기: UI 계약이 넓고 회귀 비용이 큼.
- `SnapshotStore` FrozenDictionary 재작성: 동시성 계약이 테스트로 고정됨.
- `PlatformError` record 제거: 호출부가 많고 이득이 작음.
- `SQLitePCLRaw.bundle_e_sqlite3` 제거: Linux 컨테이너에서 native sqlite가 필요할 수 있음.

## 같은 릴리스에서 고친 버그

- 스트리머를 커스텀 카테고리에 드롭하면 그 카테고리가 `customCategories`에서 지워지던 처리 제거.
- `ApplyPartial`이 더 오래된 시각의 부분 결과를 최신 성공 스냅샷 위에 덮지 못하게 `CanApply` 적용.

## 검증

기존 `Raider.Web.Tests`가 계약이다. Given 기존 시나리오 / When 리팩터 / Then 같은 테스트가 통과. 위 두 버그는 회귀 테스트와 소스 루프로 고정.
