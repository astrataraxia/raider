# Goal 5. 주기 수집과 검색 스냅샷 완성.

## 목표.

CHZZK과 SOOP을 독립적으로 수집하고 완성된 최신 목록, 태그 인덱스, 검색 읽기 모델을 원자적으로 교체한다.

## 산출물.

- 플랫폼별 독립 `BackgroundService`.
- 플랫폼별 마지막 정상 목록과 오류 상태.
- 정렬된 `LiveSnapshot`, 태그 인덱스, 검색 텍스트.
- `Interlocked.Exchange` 기반 잠금 없는 읽기 경로.
- `/health/ready`와 구조화 로그.

## Task.

### Task 5.1. 스냅샷 생성과 원자 교체를 구현한다.

- [x] 초기 스냅샷, 완성 스냅샷 교체, 동시 읽기, 오래된 결과 거부 테스트를 작성한다.
- [x] 병합, 중복 제거, 정렬, 태그 인덱스 생성을 구현한다.
- [x] 완성된 스냅샷 참조만 `Interlocked.Exchange`로 교체한다.

### Task 5.2. 플랫폼 실패를 격리한다.

- [x] 한 플랫폼 실패 중 다른 플랫폼 갱신, 마지막 정상 목록 유지, 오류 상태 테스트를 작성한다.
- [x] 플랫폼별 상태를 독립 보관하고 성공 결과만 반영한다.

### Task 5.3. 주기 실행과 재시도를 구현한다.

- [x] 시작 직후 수집, 주기 실행, 재시도 가능 오류, 중복 실행 방지, 정상 종료 테스트를 작성한다.
- [x] 플랫폼별 `BackgroundService`와 제한된 백오프를 구현한다.

### Task 5.4. 준비 상태와 검색 성능을 검증한다.

- [x] 첫 수집 전후 `/health/ready` 테스트를 작성한다.
- [x] 대표 방송 수와 태그 수에서 검색과 태그 필터 시간을 측정한다.
- [x] 수집과 검색 중 화면 읽기가 외부 I/O나 잠금을 기다리지 않는지 확인한다.

## 완료 조건.

- 한 플랫폼 지연과 실패가 다른 플랫폼과 화면 읽기를 막지 않는다.
- 실패 시 마지막 정상 목록을 유지한다.
- 스냅샷과 태그 인덱스가 한 번에 교체된다.
- 검색 경로가 외부 서비스와 데이터베이스 없이 성능 목표를 만족한다.
