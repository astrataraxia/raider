# Raider v1.3.2 Favicon 및 즐겨찾기 카테고리 필터 구현 계획

## Goal

- **Favicon 정상 노출**: SVG Favicon이 일부 환경에서 캐싱 혹은 리포트 오류로 노출되지 않는 문제를 수정하고, Raider 보라색 동그라미 로고를 브라우저 탭에 안정적으로 노출시킵니다.
- **즐겨찾기 카테고리 필터**: 메인 화면에서 `[즐겨찾기]` 필터가 활성화되었을 때, 즐겨찾는 스트리머들을 지정한 카테고리별로 서브 필터링하여 조회할 수 있는 기능을 제공합니다.

## 성공 조건

1. **Favicon 안정 노출**:
   - `Index.cshtml`에 캐시 버스팅 변수(`?v=1.3.2`)가 붙은 favicon 경로를 설정하고, `type="image/svg+xml"` 및 `rel="icon"` 속성을 부여한다.
   - `Program.cs`에서 `/favicon.ico` 호출 시 `/favicon.svg`로 Redirect 처리하여, 404로 인한 브라우저의 아이콘 거부 현상을 완전히 방지한다.
2. **즐겨찾기 카테고리별 필터**:
   - 메인 화면에서 `[즐겨찾기]` 필터를 켜면, 즐겨찾기에 속한 고유 카테고리 목록이 태그 형태의 서브 필터 바(`카테고리 필터`)로 화면에 노출된다.
   - 특정 카테고리를 선택하면, 메인 화면 라이브 목록에 해당 카테고리에 속한 즐겨찾기 스트리머의 방송만 정확하게 노출된다.
   - 카테고리 필터 선택 상태가 플랫폼 필터, 검색어, 페이지네이션과 완벽히 동기화된다.
   - 카테고리가 켜지면 적용된 액티브 필터 칩에 `카테고리: [카테고리명]` 칩이 추가되며, 칩의 `×` 버튼을 눌러 필터를 해제할 수 있다.

## Verification Plan

### Automated Tests
- `dotnet test`로 전체 유닛 및 E2E 테스트 검증.
- 새롭게 추가된 카테고리 필터 관련 쿼리 매개변수 유효성을 검증하는 테스트 코드를 작성하거나 기존 테스트를 보완.

### Manual Verification
- 브라우저를 열어 Raider 보라색 동그라미 Favicon이 탭에 안정적으로 뜨는지 검증.
- `[즐겨찾기]` 필터를 눌렀을 때 즐겨찾기 카테고리들(`기본` 등)이 필터 바로 등장하는지 검증.
- 특정 카테고리를 선택했을 때 해당 카테고리의 스트리머만 홈 화면에 표시되는지 검증.
- 칩 제거 버튼 클릭 시 카테고리 필터가 해제되는지 검증.
