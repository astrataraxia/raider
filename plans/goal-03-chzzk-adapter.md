# Goal 3. CHZZK 수집 어댑터 완성.

## 목표.

CHZZK 공식 Open API의 전체 현재 라이브 목록과 태그를 안전하게 순회하고 공통 `LiveStream` 목록으로 변환한다.

## 선행 조건.

- Goal 1 CHZZK 공식 fixture와 태그 필드가 준비되어야 한다.
- Goal 2 공통 모델과 오류 계약이 완료되어야 한다.

## 산출물.

- `IHttpClientFactory`로 등록한 CHZZK typed client와 내부 경계 DTO.
- 전체 페이지 수집, 태그 변환, fixture 계약 테스트.
- 기본 테스트와 분리된 실제 API 스모크 테스트.

## Task.

### Task 3.1. 첫 페이지와 태그를 변환한다.

- [x] 정상 fixture의 필수 필드, 태그, 카테고리가 공통 모델로 변환되는 실패 테스트를 먼저 작성한다.
- [x] 선택 필드 누락 허용과 필수 필드 누락 제외 테스트를 작성한다.
- [x] 최소 DTO와 변환을 구현한다.

### Task 3.2. 전체 페이지를 수집한다.

- [x] 다음 cursor 요청, 마지막 페이지 종료, 중복 제거, 중간 실패 폐기 테스트를 먼저 작성한다.
- [x] 로컬 HTTP 서버와 실제 `HttpClient`로 페이지 순회를 구현한다.

### Task 3.3. 인증과 오류를 처리한다.

- [x] Client 인증 헤더, `401`, `403`, `429`, `5xx`, 타임아웃 매핑 테스트를 작성한다.
- [x] 인증정보가 로그와 오류에 노출되지 않는 typed client를 구현한다.

### Task 3.4. 실제 API 스모크 테스트를 수행한다.

- [x] 전체 방송 수, 페이지 수, 수집 시간, 중복 수, 태그 포함률을 기록한다.
- [x] fixture와 실제 응답 호환성을 확인한다.
