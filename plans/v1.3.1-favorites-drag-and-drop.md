# Raider v1.3.1 즐겨찾기 폴더링 및 드래그 앤 드롭 카테고리 관리 계획

## Goal

즐겨찾기 카테고리 관리 사용성을 획기적으로 개선합니다. 스트리머들의 정렬 순서를 시청자 수 기준으로 변경하고, 카테고리를 자유롭게 접고 펼 수 있도록 지원합니다. 또한 기존의 드롭다운 방식 대신 스트리머 이름 및 카테고리를 드래그 앤 드롭하여 쉽게 옮기거나 재배치할 수 있게 합니다. 추가로 브라우저 탭에서 Favicon이 제대로 나오지 않는 현상을 해결합니다.

## 성공 조건

1. **카테고리 접고 펼치기**: 즐겨찾기 사이드바 내의 카테고리(📁)를 클릭하면 해당 카테고리가 접히거나 펼쳐지며, Chevron 표시(`▼` / `▶`)와 상태가 `localStorage`에 유지되어 페이지 새로고침 시에도 보존된다.
2. **카테고리 순서 재배치**: 카테고리 헤더를 드래그 앤 드롭하여 순서를 변경할 수 있으며, 이 순서가 `localStorage`에 저장되어 유지된다.
3. **스트리머 드래그 앤 드롭 이동**: 스트리머 행을 다른 카테고리(혹은 헤더)로 드래그 앤 드롭하여 소속 카테고리를 직관적으로 변경할 수 있다.
4. **스트리머 시청인원 기준 정렬**: 각 카테고리 내부의 스트리머들이 라이브 스트리머 우선으로 시청자 수가 많은 순으로 자동 정렬된다. 오프라인 스트리머들은 그 아래에 이름순으로 정렬된다.
5. **새 카테고리 생성**: 즐겨찾기 상단의 `➕` 버튼을 통해 새 빈 카테고리를 생성할 수 있으며, 여기에 스트리머를 드래그하여 집어넣을 수 있다.
6. **탭 Favicon 정상 노출**: 브라우저 탭에 SVG Favicon이 정상 표시되며, 직접 `/favicon.ico`를 요청했을 때도 SVG를 올바른 MIME Type으로 서빙한다.

## Verification Plan

### Automated Tests
- `dotnet test`로 기존 테스트 전체 실행.
- E2E Playwright 테스트(`HomePagePlaywrightTests.cs`) 실행 및 빌드 확인.

### Manual Verification
- 카테고리 `➕` 버튼으로 빈 카테고리를 정상 추가할 수 있는지 확인.
- 스트리머 아이템을 드래그하여 다른 카테고리에 드롭했을 때 API 호출 및 카테고리 이동이 정상 처리되는지 확인.
- 카테고리 헤더를 드래그하여 순서를 위아래로 바꿀 수 있는지 확인.
- 카테고리 헤더 클릭 시 접히고 펼쳐지며 새로고침 후에도 유지되는지 확인.
- 시청자 수가 많은 순서대로 사이드바에 정렬되는지 확인.
- 브라우저 탭 아이콘이 깨지지 않고 정상 표시되는지 확인.
