# Raider v1.3.0 즐겨찾기 카테고리화 및 탐색 고도화 계획.

## Goal.

즐겨찾기 항목의 시각적 밀도를 높이고 실시간 시청자 수를 표시하며, 스트리머들을 카테고리별로 관리(드롭다운 이동 및 추가)할 수 있게 합니다. 또한 메인 화면에서 즐겨찾는 방송인만 필터링하여 볼 수 있는 필터 기능과 브랜드 Favicon을 함께 도입합니다.

## 성공 조건.

- 즐겨찾기 사이드바 내의 아이템 간격이 기존보다 좁아져 높은 정보 밀도를 제공한다.
- 라이브 상태인 즐겨찾기 방송인 우측에 현재 시청자 수가 배지 형태로 정상 표시된다.
- 즐겨찾는 방송인을 카테고리별(기본값 `'기본'`)로 그룹화하여 사이드바에 📁 폴더 단위로 표시한다.
- 각 스트리머 옆의 카테고리 선택 드롭다운을 통해 기존 카테고리로 이동하거나 `➕ 새 카테고리...`를 생성하여 즉시 소속을 변경할 수 있다.
- 메인 화면 필터 영역에 `[즐겨찾기]` 버튼이 추가되어, 활성화 시 현재 내 즐겨찾기 목록에 등록된 스트리머들의 실시간 방송만 필터링되어 노출된다.
- 즐겨찾기 필터가 켜진 상태에서 다른 플랫폼 필터, 태그 필터, 검색어가 결합되어 정상 작동한다.
- 브라우저 탭에 Raider 브랜드 전용 벡터(Favicon.svg) 아이콘이 노출된다.
- 기존 DB 파일이 있을 때 자동으로 새 `category` 컬럼 마이그레이션이 수행되어 이전 즐겨찾기 목록이 정상 보존된다.

## 범위 밖.

- 카테고리 자체의 독립적인 삭제/이름 변경 단독 API (카테고리는 스트리머가 배정되어 있을 때만 자동 생성 및 유지됨).
- 즐겨찾기 드래그 앤 드롭 이동 (Vanilla JS와 접근성 강화를 위해 간결하고 강력한 Select 드롭다운으로 대체).
- 외부 카테고리 추천 API 및 동기화.

## 핵심 결정.

### SQLite 스키마 마이그레이션.
- `favorites` 테이블에 `category TEXT NOT NULL DEFAULT '기본'` 컬럼을 추가한다.
- DB 초기화 단계(`InitializeAsync`)에서 `ALTER TABLE` 구문을 try-catch로 예외 격리 실행하여, 기존 데이터가 존재하면 컬럼을 신설하고 `'기본'` 값으로 안전하게 마이그레이션한다.

### 카테고리 변경 API.
- `PUT /api/favorites/{platform}/{channelId}/category` 엔드포인트를 추가하고 JSON Body `{ "category": "..." }`를 입력받아 특정 즐겨찾기의 카테고리 컬럼을 업데이트한다.
- 위조 요청 방지를 위해 Antiforgery 검증을 적용한다.

### UI 및 스케일링.
- 사이드바 내 즐겨찾기 목록을 `category` 기준 Dictionary로 그룹화하여 분류 렌더링한다. 비어 있는 카테고리 그룹은 노출하지 않는다.
- 각 스트리머 행에 `<select>` 드롭다운을 인라인 배치하고, 현재 모든 카테고리 리스트와 `➕ 새 카테고리...` 옵션을 동적으로 추가하여 빠른 카테고리 생성 및 관리를 실현한다.
