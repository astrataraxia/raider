# Goal 4. SOOP 수집 어댑터 완성.

## 목표.

Goal 1에서 채택한 공개 웹 JSON으로 전체 현재 라이브 목록과 태그를 수집하고 공통 `LiveStream` 목록으로 변환한다.

## 산출물.

- SOOP typed client와 내부 경계 DTO.
- `current_view_cnt`와 태그 필드 변환.
- `broad_start` 전체 페이지 수집과 응답 변경 감지.
- fixture 계약 테스트와 실제 스모크 테스트.

## Task.

### Task 4.1. 첫 페이지와 태그를 변환한다.

- [x] 필수 공통 필드와 `current_view_cnt` 변환 실패 테스트를 먼저 작성한다.
- [x] `auto_hashtags`, `category_tags`, `hash_tags`, `lang_tags` 정규화 테스트를 작성한다.
- [x] 썸네일 누락 허용과 필수 필드 누락 제외 테스트를 작성한다.
- [x] 최소 DTO와 변환을 구현한다.

### Task 4.2. 전체 목록을 수집한다.

- [x] `broad_start` 페이지 순회, 마지막 페이지, 중복 제거, 중간 실패 폐기 테스트를 작성한다.
- [x] 요청 쿠키 없이 로컬 HTTP 서버와 실제 `HttpClient`로 구현한다.

### Task 4.3. 변경과 차단을 감지한다.

- [x] JSON 구조 변경, 차단 페이지, 제한 초과, 타임아웃, `5xx` 오류 분류 테스트를 작성한다.
- [x] 계약 오류를 정상 빈 목록으로 처리하지 않는 구현을 만든다.

### Task 4.4. 실제 스모크 테스트를 수행한다.

- [x] 전체 방송 수, 고유 방송 수, 중복 수, 페이지 수, 시간, 태그 포함률을 기록한다.
- [x] 반복 호출로 변경과 차단 가능성을 확인한다.
