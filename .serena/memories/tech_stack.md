# Tech Stack

- .NET 10 and C#.
- ASP.NET Core Razor Pages for the web UI.
- `BackgroundService` and `IHttpClientFactory` for platform collection.
- `System.Text.Json` for external response parsing.
- Immutable in-memory snapshots with `ImmutableArray`, `FrozenDictionary`, and `Interlocked.Exchange`.
- xUnit and Playwright for .NET for automated verification.
- No permanent database, Redis, external search engine, Entity Framework Core, SignalR, or MediatR in the current scope.
