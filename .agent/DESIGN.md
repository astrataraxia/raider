# Raider 디자인 시스템.

## 1. 디자인 목표.

Raider는 CHZZK과 SOOP의 현재 방송을 빠르게 비교하고 원본 방송으로 이동하는 다크 모드 전용 탐색 화면이다.

디자인 우선순위.

1. 방송 썸네일, 방송인 이름, 제목, 시청자 수가 빠르게 읽혀야 한다.
2. 많은 타일이 있어도 화면이 복잡하거나 답답하게 느껴지지 않아야 한다.
3. CHZZK과 SOOP을 명확히 구분하되 어느 한 플랫폼의 복제 화면처럼 보이지 않아야 한다.
4. 데스크톱과 모바일 모두에서 정보 밀도와 터치 편의성을 유지해야 한다.
5. 외부 폰트와 대형 프론트엔드 라이브러리 없이 빠르게 렌더링되어야 한다.

디자인 키워드.

- 어두운 레이더 화면.
- 밀도 높은 라이브 탐색.
- 절제된 플랫폼 색상.
- 선명한 썸네일과 숫자.
- 빠르고 조용한 상호작용.

## 2. 화면 구조.

홈 화면은 세 영역으로 구성한다.

```text
┌──────────────────────────────────────────────────────────────┐
│ Raider   현재 방송 248개        마지막 갱신 21:42   상태 ● │
├──────────────────────────────────────────────────────────────┤
│ [전체] [CHZZK] [SOOP] [태그] [방송인, 제목 또는 태그 검색] │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  방송 타일 그리드.                                           │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

- 상단 바는 앱 이름, 현재 방송 수, 마지막 갱신 시각, 수집 상태를 보여준다.
- 필터 바는 플랫폼 필터, 태그 필터, 검색 입력을 제공한다.
- 본문은 시청자 수 내림차순 라이브 타일 그리드다.
- 데스크톱에는 접이식 공용 즐겨찾기 사이드바를 두고 모바일에서는 드로어로 전환한다.

## 3. 색상.

다크 모드만 지원한다. 모든 색상은 CSS custom property로 정의한다.

### 중립 색상.

| Token | 값 | 용도 |
| --- | --- | --- |
| `--color-bg` | `#090B10` | 페이지 배경. |
| `--color-surface-1` | `#10131A` | 상단 바, 필터 바 배경. |
| `--color-surface-2` | `#171B24` | 타일 배경. |
| `--color-surface-3` | `#202632` | 호버, 입력 배경, 강조 표면. |
| `--color-border` | `#2A3140` | 기본 경계선. |
| `--color-border-strong` | `#3A4456` | 포커스 전 경계선. |
| `--color-text-primary` | `#F4F7FB` | 제목과 주요 숫자. |
| `--color-text-secondary` | `#AAB3C2` | 방송인 이름과 보조 정보. |
| `--color-text-muted` | `#727D90` | 갱신 시각과 비활성 텍스트. |

### Raider 브랜드 색상.

| Token | 값 | 용도 |
| --- | --- | --- |
| `--color-brand` | `#8B7CFF` | 활성 필터, 포커스 링, 앱 강조. |
| `--color-brand-hover` | `#A397FF` | 강조 요소 호버. |
| `--color-brand-soft` | `#8B7CFF24` | 선택 상태 배경. |

브랜드 색상은 화면 면적의 10% 이상을 차지하지 않게 한다.

### 플랫폼 색상.

| Token | 값 | 용도 |
| --- | --- | --- |
| `--color-chzzk` | `#00E56B` | CHZZK 뱃지와 필터 표시. |
| `--color-chzzk-soft` | `#00E56B20` | CHZZK 뱃지 배경. |
| `--color-soop` | `#2D8CFF` | SOOP 뱃지와 필터 표시. |
| `--color-soop-soft` | `#2D8CFF20` | SOOP 뱃지 배경. |

플랫폼 색상은 뱃지, 필터 점, 포커스 보조 표현에만 사용한다. 타일 전체 배경에는 사용하지 않는다.

### 상태 색상.

| Token | 값 | 용도 |
| --- | --- | --- |
| `--color-success` | `#38D996` | 정상 수집 상태. |
| `--color-warning` | `#F6B94A` | 오래된 목록과 부분 장애. |
| `--color-danger` | `#FF667A` | 초기 수집 실패와 전체 장애. |
| `--color-live` | `#FF4D67` | 라이브 시청자 수 점 표시. |

상태는 색상만으로 전달하지 않고 아이콘 또는 텍스트를 함께 표시한다.

## 4. 타이포그래피.

외부 폰트 CDN을 사용하지 않는다.

### 폰트 스택.

```css
font-family:
  Pretendard,
  Inter,
  "Noto Sans KR",
  "Segoe UI",
  system-ui,
  -apple-system,
  sans-serif;
```

Pretendard가 로컬 환경에 없으면 시스템 한글 폰트로 자연스럽게 대체한다. 숫자는 `font-variant-numeric: tabular-nums`를 적용해 시청자 수 비교 시 자리 폭이 흔들리지 않게 한다.

### 글자 크기.

| Token | 크기 / 줄 높이 | 굵기 | 용도 |
| --- | --- | --- | --- |
| `--text-xs` | `12px / 16px` | 500 | 뱃지, 갱신 시각. |
| `--text-sm` | `13px / 18px` | 500 | 방송인 이름, 필터. |
| `--text-md` | `15px / 21px` | 600 | 방송 제목. |
| `--text-lg` | `18px / 24px` | 700 | 화면 제목, 방송 수. |
| `--text-xl` | `24px / 30px` | 750 | 앱 이름 또는 빈 상태 제목. |

규칙.

- 방송 제목은 최대 두 줄로 표시한다.
- 방송인 이름은 한 줄로 표시한다.
- 뱃지와 상태 문구는 모두 대문자로 표시하지 않는다.
- 본문 폰트 크기는 모바일에서도 `13px` 아래로 내리지 않는다.

## 5. 간격과 크기.

4px 기반 간격 체계를 사용한다.

| Token | 값 |
| --- | --- |
| `--space-1` | `4px` |
| `--space-2` | `8px` |
| `--space-3` | `12px` |
| `--space-4` | `16px` |
| `--space-5` | `20px` |
| `--space-6` | `24px` |
| `--space-8` | `32px` |
| `--space-10` | `40px` |

크기 규칙.

- 콘텐츠 최대 폭은 `1680px`다.
- 페이지 좌우 여백은 데스크톱 `24px`, 태블릿 `20px`, 모바일 `12px`다.
- 상단 바 높이는 데스크톱 `64px`, 모바일 `56px`다.
- 필터와 입력의 최소 높이는 `40px`다.
- 클릭 또는 터치 영역은 최소 `44px`다.

## 6. 모서리, 경계, 그림자.

| Token | 값 | 용도 |
| --- | --- | --- |
| `--radius-sm` | `6px` | 뱃지. |
| `--radius-md` | `10px` | 입력, 필터. |
| `--radius-lg` | `14px` | 방송 타일. |
| `--shadow-tile` | `0 12px 32px #00000030` | 타일 호버. |

- 기본 타일은 `1px` 경계선만 사용한다.
- 타일 호버 시 배경색, 경계선, 작은 이동과 그림자를 함께 변경한다.
- 과한 글로우, 네온 테두리, 유리 효과는 사용하지 않는다.

## 7. 라이브 타일.

### 구조.

```text
┌──────────────────────────────────┐
│ [CHZZK]                  ● 8,432 │
│                                  │
│          16:9 썸네일             │
│                                  │
├──────────────────────────────────┤
│ 방송 제목 최대 두 줄             │
│ 방송인 이름                      │
└──────────────────────────────────┘
```

타일 전체가 원본 방송 페이지로 이동하는 하나의 링크다.

### 규격.

- 썸네일 비율은 `16 / 9`로 고정한다.
- 이미지에는 `loading="lazy"`와 `decoding="async"`를 적용한다.
- 첫 화면 상단 타일 일부만 eager 로딩을 허용한다.
- 플랫폼 뱃지는 썸네일 좌측 상단에 둔다.
- 시청자 수는 라이브 점과 함께 썸네일 우측 상단에 둔다.
- 썸네일 오버레이는 `#00000099` 배경으로 이미지와 관계없이 읽히게 한다.
- 정보 영역 패딩은 데스크톱 `12px`, 모바일 `10px`다.
- 타일 배경은 `--color-surface-2`, 경계는 `--color-border`를 사용한다.

### 상태.

- 기본: 그림자 없이 정적 상태.
- 호버: `translateY(-2px)`, 강한 경계선, `--shadow-tile`.
- 포커스: `2px` 브랜드 포커스 링과 `2px` 오프셋.
- 활성 클릭: 이동 효과를 제거하고 표면을 한 단계 어둡게 한다.
- 썸네일 실패: 플랫폼별 기본 이미지와 방송 정보는 유지한다.

타일 호버 전환 시간은 `140ms`이며 `prefers-reduced-motion`에서는 이동 효과를 제거한다.

## 8. 타일 그리드.

CSS Grid를 사용한다.

```css
grid-template-columns: repeat(auto-fill, minmax(min(100%, 260px), 1fr));
```

권장 열 수.

| 화면 폭 | 열 수 목표 | 간격 |
| --- | --- | --- |
| `>= 1440px` | 4열 이상 | `20px` |
| `1024px ~ 1439px` | 4열 | `16px` |
| `768px ~ 1023px` | 3열 | `16px` |
| `480px ~ 767px` | 2열 | `12px` |
| `< 480px` | 1열 | `12px` |

모든 타일은 정보 영역 높이를 일정하게 유지한다. 긴 제목 때문에 그리드 행 높이가 달라지지 않아야 한다.

## 9. 상단 바.

### 데스크톱.

- 왼쪽에 `Raider` 워드마크와 현재 방송 수를 둔다.
- 오른쪽에 마지막 갱신 시각과 전체 수집 상태를 둔다.
- 스크롤 시 상단에 고정한다.
- 배경은 `--color-bg`에 작은 불투명도와 blur를 적용할 수 있다.

### 모바일.

- 첫 줄에 워드마크와 상태를 둔다.
- 현재 방송 수와 마지막 갱신은 더 작은 보조 문구로 표시한다.
- 필터 바와 겹치지 않게 전체 높이를 제한한다.

워드마크는 텍스트만 사용한다. 초기 MVP에서는 별도 로고 이미지와 아이콘을 만들지 않는다.

## 10. 필터와 검색.

### 플랫폼 필터.

- `전체`, `CHZZK`, `SOOP` 세 개의 세그먼트 버튼을 사용한다.
- 기본값은 `전체`다.
- 선택된 버튼은 브랜드 소프트 배경과 밝은 텍스트를 사용한다.
- 플랫폼 버튼에는 작은 플랫폼 색상 점을 함께 표시한다.

### 검색.

- 방송인 이름, 방송 제목, 태그를 검색한다.
- placeholder는 `방송인, 제목 또는 태그 검색`이다.
- 검색 아이콘, 입력값, 지우기 버튼만 제공한다.
- 데스크톱 최대 폭은 `360px`, 모바일에서는 전체 폭을 사용한다.

### 태그 필터.

- 스냅샷에 존재하는 태그 중 방송 수가 많은 태그를 선택 가능한 칩으로 표시한다.
- 기본 화면에는 태그를 과도하게 나열하지 않고 펼침 영역에서 전체 태그를 탐색한다.
- 선택 태그는 명확한 활성 상태와 제거 동작을 제공한다.
- 태그는 타일에 최대 3개만 표시하고 나머지는 검색과 필터에만 사용한다.

플랫폼, 태그, 검색 결과는 URL query parameter로 표현해 새로고침과 링크 공유 후에도 유지한다.

## 11. 상태 화면.

### 첫 수집 전.

- 실제 타일과 동일한 크기의 스켈레톤 8~12개를 표시한다.
- 스켈레톤은 느린 펄스만 사용하고 과한 shimmer 효과는 피한다.

### 현재 방송 없음.

- 중앙 정렬된 짧은 문구를 표시한다.
- 제목은 `현재 방송을 찾지 못했습니다.`다.
- 수집 정상 여부와 마지막 갱신 시각을 함께 표시한다.

### 플랫폼 일부 장애.

- 정상 플랫폼 타일은 그대로 보여준다.
- 그리드 위에 낮은 높이의 경고 배너를 표시한다.
- 실패 플랫폼, 마지막 정상 갱신 시각, 재시도 중임을 표시한다.

### 초기 수집 실패.

- 오류 상태와 재시도 중임을 명확히 표시한다.
- 빈 목록을 정상 상태처럼 표현하지 않는다.

## 12. 반응형 동작.

- 즐겨찾기 사이드바는 데스크톱에서 본문 왼쪽에 표시하며 접으면 좁은 레일만 유지한다.
- 모바일 즐겨찾기는 기본 닫힘 드로어로 표시하고 본문을 밀거나 가로 스크롤을 만들지 않는다.
- 모바일 드로어는 Escape 닫기, 포커스 복귀, 배경 상호작용 차단과 스크롤 잠금을 지원한다.
- 필터 바는 데스크톱에서 가능한 한 한 줄로 유지하고, 모바일에서 플랫폼, 태그, 검색을 자연스럽게 줄바꿈한다.
- 모바일에서 상단 바는 정보량을 줄이고 타일 탐색 공간을 우선한다.
- 타일은 모바일에서도 썸네일과 필수 정보가 모두 보여야 한다.
- 가로 스크롤이 생기면 안 된다.
- 모바일 hover 효과에 의존하지 않는다.

## 13. 접근성.

- 본문 텍스트와 배경의 명암 대비는 WCAG AA를 목표로 한다.
- 모든 인터랙션은 키보드로 접근 가능해야 한다.
- 즐겨찾기 토글과 사이드바 열기 상태는 접근 가능한 이름과 `aria-expanded`로 전달한다.
- `:focus-visible` 상태를 명확히 표시한다.
- 플랫폼과 상태를 색상만으로 구분하지 않는다.
- 썸네일 대체 텍스트는 `{방송인 이름}의 방송 썸네일` 형식을 사용한다.
- 외부 링크임을 스크린 리더가 알 수 있게 보조 문구를 제공한다.
- `prefers-reduced-motion`을 지원한다.

## 14. 아이콘과 이미지.

- 아이콘은 한 종류의 단순한 선형 SVG 스타일만 사용한다.
- 아이콘 크기는 기본 `16px`, 버튼에서는 `18px`다.
- 이모지를 UI 아이콘으로 사용하지 않는다.
- 플랫폼 공식 로고 사용이 필요하면 각 브랜드 가이드를 확인한 뒤 적용한다.
- 기본 썸네일은 Raider 중립 배경과 플랫폼 텍스트 뱃지로 만든다.

## 15. 성능 디자인 규칙.

- 외부 폰트 요청을 만들지 않는다.
- 초기 화면에 대형 JavaScript 번들을 포함하지 않는다.
- 썸네일 URL만 사용하며 이미지 프록시와 서버 캐시는 두지 않는다.
- 이미지에 크기 또는 `aspect-ratio`를 지정해 레이아웃 이동을 방지한다.
- 첫 화면 바깥 이미지는 지연 로딩한다.
- CSS는 단일 파일로 유지하고 사용하지 않는 스타일을 포함하지 않는다.
- 화면 요청은 현재 메모리 스냅샷만 사용한다.

## 16. 디자인 토큰 예시.


## 17. 디자인 검증 체크리스트.

### 데스크톱.

- [ ] 1440px에서 4열 이상이 자연스럽고 타일이 지나치게 넓지 않다.
- [ ] 방송인 이름, 제목, 시청자 수를 빠르게 구분할 수 있다.
- [ ] 상단 바와 필터 바가 콘텐츠를 과도하게 가리지 않는다.
- [ ] CHZZK과 SOOP을 뱃지로 즉시 구분할 수 있다.

### 모바일.

- [ ] 375px에서 가로 스크롤이 없다.
- [ ] 타일 링크의 터치 영역이 충분하다.
- [ ] 필터와 검색을 한 손으로 사용할 수 있다.
- [ ] 제목과 방송인 이름이 읽을 수 있는 크기다.

### 상태와 접근성.

- [ ] 스켈레톤, 빈 목록, 부분 장애, 초기 실패가 서로 구분된다.
- [ ] 키보드 포커스가 명확하다.
- [ ] 색상을 제거해도 플랫폼과 상태를 이해할 수 있다.
- [ ] `prefers-reduced-motion`에서 불필요한 이동 효과가 없다.

이 문서는 현재 화면의 디자인 계약이다. 변경이 필요하면 CSS부터 임의로 바꾸지 않고 먼저 이 문서를 수정하고 변경 이유를 기록한다. 구현 검증 결과는 `RELEASES.md`에 보관한다.
